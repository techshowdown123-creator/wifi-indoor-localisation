# P6 — Wi-Fi Indoor Localisation (Group G6 · Paracetamol)

Predict which of 4 rooms a smartphone is in from the signal strength (RSSI, dBm) of 7 Wi-Fi access points.
We do it first **without labels** (K-Means) and then **with labels** (KNN, SVM, Decision Tree, Random Forest, Logistic Regression), and finally test robustness to router failure and measurement noise.

## Headline results
| Model | Nested 5-fold CV macro-F1 (mean ± SD) | Test macro-F1 | Test macro-F1 at ±5 dBm noise |
|---|---|---|---|
| Dummy (stratified) | 0.254 ± 0.037 | 0.238 | 0.238 |
| Logistic Regression | 0.979 ± 0.011 | 0.983 | 0.891 ± 0.015 |
| **KNN** (selected) | **0.984 ± 0.004** | **0.990** | 0.891 ± 0.016 |
| SVM (RBF) | 0.981 ± 0.008 | 0.980 | 0.889 ± 0.016 |
| Decision Tree | 0.974 ± 0.007 | 0.973 | 0.825 ± 0.012 |
| Random Forest | 0.981 ± 0.008 | 0.983 | 0.856 ± 0.015 |

K-Means (K = 4, labels hidden) agrees with the true rooms at ARI = 0.820 ± 0.036 (0.881 ± 0.026 on raw dBm).

## How to run
```bash
python -m venv .venv
# Windows:  .venv\Scripts\activate      macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook P6_WiFi_Localisation.ipynb      # then Kernel → Restart & Run All
```
Headless check that it runs top to bottom (about 2 minutes):
```bash
jupyter nbconvert --to notebook --execute --inplace P6_WiFi_Localisation.ipynb
```
